# TMDB API Testing

This project tests **The Movie Database (TMDB) API** using Postman to validate API functionality and responses.

## Tools Used
- Postman
- REST API
- JSON
- JavaScript (Postman Tests)

## Project Files
- `API Testing Assignment.postman_collection.json` – Postman collection containing API requests and tests.
- `API_Testing_Assignment (TMDB).docx` – Assignment documentation.

## How to Run
1. Open Postman.
2. Import `API Testing Assignment.postman_collection.json`.
3. Configure your TMDB API authentication credentials.
4. Run the collection and review the test results.

## Purpose
Validate API responses, HTTP status codes, and returned data to help ensure reliable API functionality.
